Lab 1: Code Analysis Environment Setup

Лабораторная работа по дисциплине
«Анализ и оптимизация программного кода для ИБ».

Цель: настроить изолированную среду, запустить статические
анализаторы (Bandit, Ruff, pip-audit) на учебном уязвимом коде
и подготовить отчёт.

Инструменты: Python 3.10+, Git, venv, Bandit, Ruff, pip-audit.
